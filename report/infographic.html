Orchestration / Workflow Flow

改寫精準化 · 解析「第一台」· 多意圖偵測
▼
② Intent Router
5 類分類（4 情境 + 無工具 fallback）
▼

④ Tool Layer

⑥ Security & Governance（橫切）：injection 防護 · 兩階段確認閘 · 單輪限額 · groundedness · 稽核

核心迴圈 C-O-R-A

Context
Rewriter + Memory + 情境 prompt 組裝本輪上下文
Observe
Router 分類意圖；觀察上一輪工具回傳
Reason
Handler 推理：呼叫哪個工具、帶什麼參數
Act
執行工具 / 產生回覆；未完成回到 Observe
↺ 迴圈持續到任務完成或觸發 escalation；每圈產生 decision trace

Memory 連續性

session_id keying · viewed_listings 有序 → 序數解析（第 N 台 → viewed[N-1]）· pending_intent 延後回收次意圖
